# Grips Intelligence

> Grips Intelligence (Peekd) is an e-commerce intelligence platform providing daily online and offline product sales measurement and competitive analysis. It tracks competitor units sold, pricing, revenue per product, top sellers, and new product launches across major retailers, plus domain-level site metrics (revenue, conversion rate, AOV, traffic sources) at SKU and category level. It exposes a REST Data API (API-key auth) and an OAuth-protected remote MCP server ("Peekd Data MCP").

## APIs
- [Grips Data API (knowledge base)](https://gripsintelligence.com/knowledge-base/api): REST data API at https://app.gripsintelligence.com/api/data/v1 — POST JSON query envelope, `grips-api-key` header. Endpoints: Domain Timeseries Performance, CI Channels, RI Adwords Over Time, CI Devices.
- [Peekd Data MCP server](https://app.gripsintelligence.com/api/mcp): OAuth-protected (authorization-code + PKCE, scope `mcp`) remote MCP server exposing Grips intelligence data to agents.
